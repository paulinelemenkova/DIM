# Gathering Predictors of Biodiversity Change and Reconstructing Land Cover History in Central Apennines Using Machine Learning and Remote Sensing Data

LaTeX source for the peer-reviewed article by Polina Lemenkova.

**Published in:** *Journal of Anatolian Geography* **2025**, *2*(1), 36–47 (CC BY-SA 4.0)
**Article:** https://dergipark.org.tr/en/pub/jag/article/1684280
**DOI:** https://doi.org/10.5281/zenodo.15767237

GRASS GIS machine-learning classification (Random Forest, Decision Tree, ANN) integrated with the Python scikit-learn library, applied to a Landsat 8-9 OLI/TIRS time series for supervised and unsupervised land-cover classification and change detection.
